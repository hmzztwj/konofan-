# 04 · 安装包还原（去 mod）

## 原包

`konofan_v570_20241008.apk`，149,865,960 B，来源：虫虫助手 `ccplay.com.cn`（app_id 159256 / version_id 474763）。
**这是 Platinmods 修改版**。

| 痕迹 | 内容 |
|---|---|
| `lib/arm64-v8a/libplatinmods.so` | 2,361,960 B，mod 主体 |
| `assets/platinmodsRB.png` | 悬浮菜单图标 |
| `AndroidManifest.xml` | `<application android:name="com.vyiche.apjrwtd">`、`FloatingModMenuService`、`PMLauncher` |
| `classes4.dex` | `com.platinmods.*` 60+ 类；**并改写了 Unity 启动 Activity 的 `onCreate` 去调 `PMLauncher.init(this)`** |

最后一条是关键：**只删 so 与 manifest 会直接崩**（`UnsatisfiedLinkError: library "libplatinmods.so" not found`）。

## 三处改动

1. **Manifest**：删 `<application android:name>`、删两棵 `platinmods` 子树（45,536 → 45,256 B）。
2. **classes4.dex**：把 `PMLauncher.init(Ljava/lang/Object;)V` 首条指令改成 `0x000e`（`return-void`），
   **并重算 dex 的 SHA-1 签名与 Adler-32 校验和**。
3. **删条目**：`libplatinmods.so`、`assets/platinmodsRB.png`（799 → 797 条）。

工具：`tools/axml.py`（解析）、`tools/axml_edit.py`（改清单）、`tools/dex_patch.py`（打 dex 补丁）、
`tools/build_clean_apk.py`（重打包）、`tools/apk/uber-apk-signer.jar`（签名）。

## 踩过的坑

1. AXML 的 **UTF-16 字符串池长度字段是 2 字节**，按 1 字节读会让整池偏移 1 字节、全变乱码。
2. 字符串池里的属性名是裸的 `name`，不含 `android:` 前缀（命名空间在别处）。
3. 删元素必须**先按属性过滤、再判断整块删除**，否则 `<application android:name=…>` 会把整个 application 删掉。
4. `attributeCount` 在 chunk 内偏移 **28**（不是 24）。
5. **改完 dex 不重算 checksum，ART 会整文件丢弃**，表现为看似无关的 `NoClassDefFoundError: Lcom/applovin/impl/d5$$ExternalSyntheticLambda0;`
   （该类明明在 classes4.dex 里）。
6. dex 的 `method_proto` 里 type_list 索引是 **u16**。
7. `class_data_item` 必须先跳过 static_fields + instance_fields 的 uleb128 对，才能定位 `code_off`。
