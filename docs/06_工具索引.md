# 06 · 工具索引

全部 Python 3.10，依赖：`UnityPy 1.25.4`、`pycryptodome`、`cryptography`、`capstone 6.0.0`、`Pillow`。

## 数据层

| 脚本 | 作用 |
|---|---|
| `decrypt_masterdata.py` | 用已知 key/iv 解 279 个 `.data` → JSON |
| `export_masterdata.py` | JSON → CSV（UTF-8 BOM）+ 数据总览 |
| `read_key_runtime.py` | 连 adb，从 `/proc/<pid>/mem` 读 `AesEncryption` 的 Key/Iv |
| `read_obscured.py` | 读 `ObscuredString.fakeValue`（ACTk 明文副本） |
| `patch_metadata.py` | 等长改写 `global-metadata.dat` 里的字符串字面量 |
| `so_keyscan.py` | 用 PKCS#7 oracle 扫 `.so` 里所有 8 字节对齐窗口当 AES 密钥（历史实验，0 命中） |

## 资源层

| 脚本 | 作用 |
|---|---|
| `bundle_inventory.py` | 遍历 UnityCache，导出 `bundles.csv`（851,654 行） |
| `bundle_summary.py` | 类型/容器/依赖统计 |
| `extract_assets.py` | 导出 PNG / TextAsset（`demo`/`images`/`text`/`list`） |
| `inventory.py` | catalog × 本地 → 资产清单与覆盖率 |
| `organize_assets.py` | 按容器路径硬链接分类到 `assets_sorted/` |
| `build_site.py` | 生成静态资料站（271 页，全内联，可 file:// 打开） |

## 媒体层

| 脚本 | 作用 |
|---|---|
| `cri_match.py` | SHA256 命名算法验证（7,658/7,658） |
| `cri_rename.py` | 还原明文名 + 分类硬链接 + `cri_manifest.csv` |
| `cri_name.py` | 早期尝试（hash 变体比对，已废弃） |
| `cpk.py` | CRI @UTF 解析器（**未完成**，布局对不上） |

## 剧情层

| 脚本 | 作用 |
|---|---|
| `story_probe.py` | dump Utage MonoBehaviour 字段 |
| `story_export.py` | 导出原始 Excel 网格 `out/story/*.txt` |
| `story_scripts.py` | 渲染成 `**说话人**：「台词」 <!-- cue -->` |

## 安装包

| 脚本 | 作用 |
|---|---|
| `axml.py` | AXML 解析（资源 ID → 属性名） |
| `axml_edit.py` | 删元素子树 / 删属性，重写 chunk 大小 |
| `dex_patch.py` | 定位方法并把首条指令改成 `return-void`，重算 checksum |
| `build_clean_apk.py` | 换 manifest + 换 dex + 删条目 → 重打包 |
| `build_probe_apk.py` | 换 `global-metadata.dat` → 重打包 |

## 静态分析（IL2CPP / .so）

| 脚本 | 作用 |
|---|---|
| `disasm.py` | 按 RVA 反汇编（自动做 `.rela.dyn` 重定位、注释字符串槽） |
| `trace_arm.py` | 直线寄存器跟踪，打印 `slot → 字面量` |
| `bl_in_range.py` | 列出某函数体内所有外部调用并解析方法名 |
| `find_calls.py` / `find_calls2.py` | 全量扫 BL 指令找调用者 |
| `which_method.py` | RVA → 方法名 |
| `lookup.py` | 建/查 script.json 的地址缓存 |

## 动态/网络

| 脚本 | 作用 |
|---|---|
| `dump_mem.py` | 按 `/proc/pid/maps` 分段 dump 进程内存 |
| `scan_key_mem.py` | 在内存 dump 里用 CBC 末块 oracle 扫 AES 密钥 |
| `mitm.py` | TLS 中间人（自签 CA，能转发/伪造 bootstrap） |
| `mock_api.py` | 本地 mock 服务（记录请求、回 bootstrap JSON） |
