### catalog 关键字段

固定文本为紧凑型：

- `m_LocatorId = AddressablesMainContentCatalog`
- `m_InternalIds`：54,661 条；`.bundle` 条目 23,069；其余为 `.png 12905 / .bytes 11266 / .prefab 4739 / .asset 1434 ...`
- 两类前缀：
  - `{Addressables.RuntimePath}/Android/<name>.bundle` → APK 内置组（6 个）
  - `{Wonder.Api.BundleDownloader.DataPath}/<32hex>.bundle` → 远程下载组（23k）
- `m_KeyDataString` 3.09 MB，内含 bundle 名（`<组名>_<32hex>.bundle`），**32hex 不是组名的 md5**（试过）
